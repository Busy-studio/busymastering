# Busy Auto Mastering

Streamlit frontend for Busy Auto Mastering.

## Secrets

```toml
SERVICE_ENDPOINT_URL = "https://your-service-url"
SERVICE_ACCESS_TOKEN = "your-service-token"
SERVICE_TIMEOUT_SEC = "60"
SERVICE_START_TIMEOUT_SEC = "3600"
```

Existing `PRIVATE_WORKER_URL` / `PRIVATE_WORKER_TOKEN` names are also supported for compatibility.
